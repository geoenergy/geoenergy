# geoenergy.ch

Website of the Geo-Energy, Reservoir Geology and Basin Analysis group, University of Geneva.

## Maintaining this site

This repository is published by GitHub Pages at **https://www.geoenergy.ch** from the `master` branch. Any change pushed to `master` goes live in 1–2 minutes; there is no build step.

- **Quick fix:** open the file on github.com (usually `index.html`), click the pencil icon, edit, and commit to `master`.
- **Larger change:** `git clone` the repo, preview with `python3 -m http.server 8000`, then commit and `git push`.
- **Do not delete the `CNAME` file**: it tells GitHub Pages which address serves this site.

Members of the geoenergy organization: the full guide (architecture, DNS, troubleshooting, who has access) is on the [organization page](https://github.com/geoenergy).
